# Support

This is a volunteer open source project.

- Read the [README](README.md) first.
- Use GitHub Issues for reproducible bugs and feature proposals.
- Use private vulnerability reporting for security problems.

A good bug report includes the purple-xmpp2 version, distro, Pidgin and
libpurple versions, the XMPP server software, and sanitized debug output
(Pidgin: `pidgin -d`). Never include passwords, tokens, or message contents.
